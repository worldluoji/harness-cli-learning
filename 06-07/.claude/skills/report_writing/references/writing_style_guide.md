# 中文研报写作风格指南

## 总体原则

研报写作的目标是：**用准确、专业、清晰的语言传递分析结论**。好的研报应该：

- 让读者 5 分钟内抓住核心观点
- 每个判断都有数据支撑
- 优势与风险并陈
- 专业但不晦涩

## 一、语言风格

### 推荐风格

**简洁明了**

```
✅ 公司近三年毛利率维持在 91% 以上，远高于行业平均水平。
❌ 我们可以看到，公司的毛利率在过去的三年当中，一直都是处于一个相对比较高的水平线上...
```

**专业术语精准**

```
✅ 公司通过费用率管控，毛利率与净利率均得到改善。
❌ 公司通过控制成本，使得赚钱比例上升。
```

**数据具体**

```
✅ 2024 年公司毛利率为 91.92%，较 2023 年提升 0.13 个百分点。
❌ 2024 年毛利率有所提升。
```

### 避免风格

**模糊表达**

```
❌ "大概"、"差不多"、"估计"、"或许"
✅ "预计"、"根据 X 计算"、"基于 Y 数据"
```

**绝对化表达**

```
❌ "必将"、"一定"、"稳赚"
✅ "有望"、"预计"、"存在...可能"
```

**口语化表达**

```
❌ "挺不错的"、"还行"、"差不多"
✅ "表现良好"、"符合预期"、"存在差距"
```

## 二、句式模板

### 1. 数据陈述句

```
- 公司 [指标] 从 [年份] 的 [X]% 提升至 [年份] 的 [X]%，[X] 个百分点。
- 近三年，公司 [指标] 维持在 [区间] 区间，[高于/低于/接近] 行业平均 [X]%。
- 2024 年公司实现营业收入 [X] 亿元，同比增长 [X]%。
```

### 2. 趋势分析句

```
- 公司 [指标] 在 [时间区间] 内呈现 [持续上升/波动下行/高位震荡] 态势。
- 自 [年份] 起，公司 [指标] [持续提升/逐步改善/明显下降]。
- 受 [因素] 影响，[指标] [变化]。
```

### 3. 原因分析句

```
- 这一变化主要源于 [因素1]、[因素2] 和 [因素3]。
- 主要原因在于 [因素]。
- 反映了公司 [战略/经营/管理] 方面的 [优势/调整]。
```

### 4. 对比评价句

```
- 公司 [指标] 显著高于/低于 行业平均水平 [X]%。
- 与可比公司相比，公司在 [方面] 具有 [优势/劣势]。
- [指标] 处于行业 [领先/中等/落后] 水平。
```

### 5. 风险提示句

```
- 投资者需关注 [风险类型] 风险：[具体描述]。
- 若 [假设/条件] 发生变化，可能影响 [判断/估值]。
- [现象] 可能对 [指标] 造成 [影响]，需 [应对措施]。
```

## 三、章节结构

### 章节开头

每个章节开头应该用 1-2 句话**概括全章要点**：

```
✅ 本章从盈利能力、偿债能力、运营能力、现金流四个维度，
   对公司近三年财务表现进行全面分析。

❌ 本章我们将分析公司的财务情况。
```

### 段落组织

每个段落遵循"**总-分-总**"结构：

```
【总】公司近三年盈利能力持续提升。
【分】具体表现为：
      - 毛利率从 X% 提升至 X%
      - 净利率从 X% 提升至 X%
【总】整体反映出公司经营效率的持续改善。
```

## 四、数据表达规范

### 数字格式

- 货币：万元 / 亿元 / 百万元（统一使用一种）
- 百分比：保留 2 位小数（毛利率 91.92%）
- 比率：保留 2 位小数（流动比率 4.52）
- 年份：用阿拉伯数字（2024 年）

### 表格规范

```
| 指标 | 2022 年 | 2023 年 | 2024 年 | 同比变化 |
|---|---|---|---|---|
| 毛利率 | 91.85% | 91.79% | 91.92% | +0.13 pct |
```

注意：
- 表头要明确（标明是"2024 年"还是"2024 年末"）
- 单位要明确（%还是 pct）
- 时间一致（避免"2024"和"24 年"混用）

### 图表规范

```markdown
![公司近三年盈利能力指标趋势分析](./images/盈利能力指标趋势分析.png)

如图所示，公司毛利率自 2022 年起持续高于 91%...
```

注意：
- 图片路径相对文件位置
- 图片描述简洁明了
- 图片后立即引用分析

## 五、常见错误与纠正

### 错误 1：因果关系混淆

```
❌ 公司营收增长，因此净利润大幅提升。
   （营收和净利润没有直接的因果关系，净利润还受费用、税率等影响）

✅ 公司营收同比增长 X%，叠加费用率改善，
   共同推动净利润同比增长 X%。
```

### 错误 2：数据引用不当

```
❌ 根据公司年报，公司 2024 年净利润达到 893 亿元。
   （缺少出处索引）

✅ 根据公司年报[1]，公司 2024 年净利润达 893 亿元，
   同比增长 15.24%。
```

### 错误 3：风险描述模糊

```
❌ 行业风险。
   （太空泛）

✅ 行业竞争加剧风险：随着新进入者增加，
   公司市场份额可能受到挤压，影响营收增长。
```

### 错误 4：预测不标注

```
❌ 2025 年公司将实现营收 2000 亿元。
   （预测当成事实）

✅ 预计 2025 年公司将实现营收 2000 亿元，
   同比增长约 X%。
```

### 错误 5：建议过于绝对

```
❌ 投资者应当买入。
   （绝对建议）

✅ 建议投资者根据自身风险偏好适当配置。
   或者给予"增持"评级。
```

## 六、专业术语速查

| 场景 | 推荐术语 | 避免 |
|---|---|---|
| 描述涨跌 | 提升 / 下降 / 增长 / 减少 | 涨了 / 跌了 |
| 描述程度 | 显著 / 略有 / 大幅 | 很 / 挺 / 特别 |
| 描述状态 | 持续 / 维持 / 波动 | 一直 / 不变 / 乱变 |
| 描述原因 | 主要源于 / 反映出 | 因为 / 所以 |
| 描述预测 | 预计 / 有望 / 存在可能 | 一定会 / 必须 |

## 七、研报开头钩子（吸引读者）

研报开头应该有"钩子"，让读者知道为什么要读这份报告：

```
✅ 核心观点：公司 [核心优势]，预计 [预测结论]，
   给予 "[评级]" 评级。

❌ 本报告分析公司的财务情况和未来发展。
```

好的开头模板：

```
【模板 1：价值发现型】
"在 [行业] 行业整体增速放缓的背景下，公司 [差异化优势]，
使其 [财务表现]。我们看好公司 [未来增长点]，给予 [评级]。"

【模板 2：预期差型】
市场普遍认为公司 [共识]，但我们认为 [反共识观点]，
主要原因在于 [分析]。预计 [预测结论]，给予 [评级]。

【模板 3：催化剂型】
公司 [短期催化事件] 将显著影响 [估值/业绩]，预计 [影响结论]，
给予 [评级]。
```

## 八、检查清单

写作完成后逐项检查：

### 内容质量
- [ ] 每个判断都有数据支撑
- [ ] 预测与事实明确区分
- [ ] 优势与风险并陈
- [ ] 包含明确的评级和目标价
- [ ] 风险提示完整具体

### 表达质量
- [ ] 无模糊措辞（大概、或许）
- [ ] 无绝对化表达（必涨、稳赚）
- [ ] 无口语化表达
- [ ] 句式简洁、动词精准
- [ ] 段落长度适宜（5-8 行）

### 格式质量
- [ ] 标题层级规范
- [ ] 表格列名清晰
- [ ] 图表路径正确
- [ ] 数据来源标注完整
- [ ] 数字格式统一

### 合规质量
- [ ] 包含免责声明
- [ ] 引用第三方报告注明出处
- [ ] 无投资承诺类表述
- [ ] 数据均来自公开披露
