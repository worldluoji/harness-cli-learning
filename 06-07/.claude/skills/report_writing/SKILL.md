# 研报写作技能 (Report Writing)

## 用途

本 skill 为 Agent 提供**中文投资研究报告**的写作规范、章节模板、表达惯例和质量标准。具体包括：

- **章节结构规范**：标准的研报章节顺序和层级
- **表达惯例**：专业术语、分析框架、句式套路
- **数据引用规范**：图表引用方式、数据来源标注
- **质量标准**：准确性、完整性、可读性、专业性
- **常见模板**：单公司分析、对比分析、估值结论等章节模板

## 何时使用此 skill

只要用户任务涉及以下内容，就应当使用本 skill：

- 撰写财务研报、研究报告
- 编写财务分析章节
- 撰写公司分析、行业分析
- 撰写投资建议、估值结论
- 编写研报正文（非图表、非原始数据）
- 完善研报结构、提升研报专业性
- 需要规范研报格式和表达

## 写作原则（核心）

### 1. 数据驱动

- 所有结论必须有数据支撑
- 数据来源必须明确标注
- 不编造数字、不虚构事实
- 历史数据使用实际值，预测数据必须标注"预测"字样

### 2. 客观中立

- 优势与劣势同列
- 风险与机会同列
- 避免绝对化措辞（如"必涨""稳赚"）
- 区分"事实"和"观点"

### 3. 结构清晰

- 标题层级分明（一、二、三 / （一）（二）（三））
- 每个章节先总后分、点面结合
- 重要内容用粗体或图表突出
- 段落不宜过长，5-8 行为宜

### 4. 专业准确

- 使用规范的金融术语（如"毛利率"而非"赚钱比"）
- 引用财务比率时使用统一格式
- 数字保留 2 位小数
- 同类数据保持统计口径一致

## 标准研报结构

完整的中文投资研究报告应包含以下章节：

```
# [公司名称]（股票代码）深度研究

## 一、公司概况
1.1 公司简介
1.2 主营业务
1.3 股权结构
1.4 核心竞争力

## 二、行业分析
2.1 行业概况
2.2 行业格局
2.3 行业趋势

## 三、财务分析
3.1 盈利能力
3.2 偿债能力
3.3 运营能力
3.4 现金流

## 四、对比分析
4.1 与主要竞争对手对比
4.2 优劣势分析

## 五、估值与预测
5.1 关键假设
5.2 DCF 估值
5.3 相对估值
5.4 估值结论

## 六、投资建议
6.1 投资评级
6.2 主要风险

## 七、数据来源与免责声明
```

## 章节写作模板

### 1. 公司简介章节

```markdown
## 一、公司概况

### 1.1 公司简介

[公司全称]（以下简称"公司"或"[简称]"）成立于[年份]年，
于[上市年份]年在[交易所]上市，[股票代码]。
公司主营[业务概述]，是[行业]领域的[地位]企业。
截至[年份]年[月]，公司总股本[X]股，市值约[X]亿元。

[来源：东方财富/巨潮资讯]
```

### 2. 财务分析章节

```markdown
### 3.1 盈利能力

公司近三年盈利能力呈现[持续提升/波动/下降]态势。

**毛利率**：2022-2024 年，公司毛利率分别为 [X]%、[X]%、[X]%，
[持续高于/低于]行业平均水平。2024 年毛利率较 2023 年
[提升/下降] [X] 个百分点，主要由于[原因]。

**净利率**：公司净利率从 2022 年的 [X]% [提升/下降] 至 2024 年的 [X]%，
反映[原因分析]。

[插入盈利趋势图]

**核心结论**：公司盈利能力[强/弱/中等]，主要驱动因素为[分析]。

[数据来源：公司年报、东方财富数据中心]
```

### 3. 对比分析章节

```markdown
## 四、对比分析

### 4.1 与主要竞争对手对比

公司选取 [X] 家主要竞争对手进行对比：[公司1]（[代码]）、
[公司2]（[代码]）、[公司3]（[代码]）。

[插入对比图]

**优势**：
- 在 [指标] 方面，公司以 [X]% 显著领先于竞争对手；
- 在 [指标] 方面，公司保持 [X]，体现[分析]。

**劣势**：
- 在 [指标] 方面，公司低于行业平均 [X]%，[原因分析]；
- 在 [指标] 方面，公司与头部企业差距明显，需[建议]。

**整体评价**：公司在 [方面] 具有[优势/劣势]，[综合判断]。
```

### 4. 估值结论章节

```markdown
## 五、估值与预测

### 5.4 估值结论

综合 DCF 估值和相对估值分析，公司合理估值区间为
[X]-[X] 亿元，对应每股价值 [X]-[X] 元。

**DCF 估值结果**：[X] 亿元（中心值），区间 [X]-[X] 亿元
- 假设条件：WACC=[X]%，永续增长率=[X]%，预测期=[X] 年
- 关键观察：[敏感性分析结论]

**相对估值结果**：参考可比公司 PE/PB 中位数，公司
当前估值处于[低估/合理/高估]区间。

### 6.1 投资评级

基于以上分析，给予公司"**[买入/增持/中性/减持]**"评级。

**核心投资逻辑**：
1. [逻辑1]
2. [逻辑2]
3. [逻辑3]

**主要风险**：
- [风险1]
- [风险2]
- [风险3]
```

## 常用表达模板

### 趋势分析

- "公司 [指标] 在 [时间区间] 内呈现 [持续上升/波动下行/高位震荡] 态势"
- "[指标] 从 [年份] 的 [X]% [提升/下降] 至 [年份] 的 [X]%，[X] 个百分点"
- "近三年 [指标] 维持在 [区间] 区间，[高于/低于/接近] 行业均值"

### 原因分析

- "主要原因在于 [因素1]、[因素2] 和 [因素3]"
- "受 [因素] 影响，[指标] [变化]"
- "这一变化反映了 [分析]"

### 对比评价

- "显著高于/低于 行业平均"
- "处于行业 [领先/中等/落后] 水平"
- "差距 [明显/不大/逐步缩小]"

### 投资评级

- "综合 [因素]，给予公司 [评级]"
- "建议投资者 [操作建议]"
- "需关注 [风险点]"

## 避免的表达

❌ 不推荐：
- "必涨"、"稳赚" 等绝对化措辞
- "据估计"、"大概"、"可能" 等模糊措辞
- "投资小白也能赚" 等误导性表述
- 编造的、不存在的数据

✅ 推荐：
- "基于上述分析"、"综合考虑"
- "历史数据显示"、"年报披露"
- "预计"、"预测"、"有望"

## 常见错误

| 错误 | 正确 |
|---|---|
| 数字未标注来源 | 每个数字都应有来源 |
| 优势只说优势 | 优势+劣势并存 |
| 预测当事实写 | "预计2025年达到X" 而非 "2025年是X" |
| 估值假设无依据 | 明确说明假设来源 |
| 风险只罗列 | 风险应有数据支撑 |

## 输出检查清单

写作完成后，逐项检查：

- [ ] 标题层级规范
- [ ] 章节顺序符合标准结构
- [ ] 所有数据有来源标注
- [ ] 图表有引用且能正确显示
- [ ] 数字保留 2 位小数
- [ ] 优势劣势并陈
- [ ] 风险提示完整
- [ ] 语言专业准确
- [ ] 无绝对化措辞
- [ ] 无虚构数据

## 适用场景举例

1. **单公司分析章节**：财务分析、公司基本面、估值结论

## 安全与合规

1. 所有内容必须基于公开披露数据
2. 不得包含任何投资建议之外的承诺
3. 必须包含风险提示和免责声明
4. 引用第三方报告需注明来源
