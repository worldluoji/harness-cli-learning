# 青岛啤酒（600600）竞争对手与行业均值分析

## 一、行业概况

- **行业名称**：啤酒（酒类饮料制造）
- **行业特点**：中国啤酒行业经过多年整合已形成高度集中的寡头格局，市场份额前五名（华润啤酒、青岛啤酒、百威亚太、燕京啤酒、嘉士伯（含重庆啤酒））合计市占率超过 90%。行业增速放缓但产品高端化趋势明显，吨酒价格持续提升。
- **行业规模与增速**：2024 年中国啤酒行业产量约 3,521 万千升，同比微降；行业销售收入约 1,800 亿元，高端及超高端产品占比快速提升，行业整体进入"量稳价升、利润导向"阶段。

## 四、竞争格局描述

1. **华润啤酒（0291.HK）**：行业销量龙头，雪花单品销量全球第一，2024年销量约1,095万千升，营收约386亿元；高端化推进Heineken、喜力等品牌。
2. **青岛啤酒（600600）**：品质品牌优势明显，山东根据地市场稳固；2024年销量约763万千升，营收约321亿元；高端品牌"经典1903、纯生啤酒、白啤"增长较快。
3. **百威亚太（1876.HK）**：高端市场份额第一，2024年中国区销量约900万千升，营收约55亿美元；策略聚焦超高端产品。
4. **燕京啤酒（000729）**：2024年销量约365万千升，营收约145亿元；北京、广西、内蒙三大根据地市场。
5. **重庆啤酒（600132）**：嘉士伯中国旗舰，2024年销量约301万千升，营收约143亿元；乌苏、1664等高端品牌增长强劲。
