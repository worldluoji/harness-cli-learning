# 青岛啤酒（600600）公司基本信息

## 1. 公司简介

青岛啤酒股份有限公司（以下简称"青岛啤酒"或"公司"）成立于1903年，是中国历史最悠久的啤酒生产企业之一，由德商和英商在青岛创办。公司于1993年同时在香港联交所（0168.HK）和上海证券交易所（600600.SH）上市，成为中国首家A+H两地上市的啤酒企业。

截至2025年末，公司总股本约13.64亿股，其中A股流通股本约7.91亿股，H股流通股本约6.53亿股，总市值规模约1,000亿元人民币（按2025年末股价估算），位居中国啤酒行业第二位。

公司注册地为山东省青岛市，办公地址位于青岛市市南区香港中路。按照申万行业分类，公司属于"食品饮料—酒类饮料—啤酒"行业。

（数据来源：公司2025年年度报告、东方财富）

## 2. 公司发展历程

- **1903年**：英德商人合资创办"日尔曼啤酒公司青岛股份公司"，为青岛啤酒前身。
- **1948年**：正式定名为"青岛啤酒厂"。
- **1993年**：先后在香港联交所和上海证券交易所上市，成为中国首家A+H两地上市企业。
- **2009年**：与日本朝日集团合资，公司更名为"青岛啤酒股份有限公司"。
- **2014-2017年**：先后收购山东银麦、宿迁、徐州等地方啤酒企业，进一步巩固山东和华东市场。
- **2020-2022年**：推进"双品牌+"战略，旗下拥有青岛啤酒、崂山啤酒、汉斯啤酒、王子海藻苏打水等众多品牌。
- **2023-2025年**：坚持高端化战略，主品牌"青岛啤酒"中高端及以上产品销量占比持续提升。

（数据来源：公司年报、互联网公开信息）
